* gimel
  :PROPERTIES:
  :CUSTOM_ID: gimel
  :END:

A Clojure static site generator for publishing Org-mode content, with an Emacs integration and SQLite-backed metadata.

** Description
~gimel~, like most static site generators, is an “opinionated” implementation designed around a particular workflow. It originally watched a directory for file changes and converted changed files to HTML for a static site.
I tried maintaining my websites in Markdown but found myself duplicating content I already maintained as Org-mode projects. As the sites grew, Org-mode publishing became slow, and I needed something faster.
Dissatisfied with the available Org-mode parsers outside Emacs Lisp, I took a different approach. I created an Emacs package that uses Emacs itself to export Org-mode files into HTML snippets. ~gimel.el~ correctly converts links, adds IDs to section headers, preserves file-level properties as metadata, and stores that metadata in SQLite.
~gimel.el~ can run in batch mode, but because batch startup is nearly as slow as ~org-publish~, the normal workflow exports individual files on save. The ~gimel~ server then renders the resulting content as a site.

*** Sites built with ~gimel~
- [[https://naurrnen.selfdidactic.com][Naurrnen]] - Fantasy worldbuilding project.
- [[https://chronos.selfdidactic.com][Age of Chronos]] - Hard science-fiction worldbuilding project.

** Quickstart
Get from zero to a publishing site in five minutes.

~gimel~ has two moving parts: the ~gimel~ server, a Clojure application that renders your site, and *gimel.el*, an Emacs package that converts your Org-mode files and triggers a render on every save.

*** Prerequisites

- Emacs 25.1 or later with [[https://github.com/bbatsov/projectile][Projectile]] 2.7.0 or later
- Java 11 or later
- Leiningen

*** Step 1 — Clone the repository

#+BEGIN_SRC sh
git clone https://github.com/timotheosh/gimel.git
cd gimel
#+END_SRC

*** Step 2 — Install gimel.el

Choose whichever method matches your Emacs setup.

*Doom Emacs* — add to =~/.doom.d/packages.el=, then run =doom sync=:

#+BEGIN_SRC emacs-lisp
(package! gimel
  :recipe (:host github :repo "timotheosh/gimel"
           :files ("resources/emacs/gimel.el")))
#+END_SRC

*straight.el*:

#+BEGIN_SRC emacs-lisp
(straight-use-package
 '(gimel :host github :repo "timotheosh/gimel"
         :files ("resources/emacs/gimel.el")))
#+END_SRC

*Manual* — add to your init file:

#+BEGIN_SRC emacs-lisp
(add-to-list 'load-path "~/path/to/gimel/resources/emacs")
(require 'gimel)
#+END_SRC

Also add the after-save hook so publishing happens automatically:

#+BEGIN_SRC emacs-lisp
(add-hook 'after-save-hook #'gimel-run-on-save)
#+END_SRC

*** Step 3 — Create your project

#+BEGIN_SRC sh
mkdir -p my-site/{org,html,public}
cd my-site
#+END_SRC

*** Step 4 — Configure the ~gimel~ server

Create =~/.config/gimel/my-site.toml= (or place =gimel.toml= in your project root):

#+BEGIN_SRC toml
[server]
port           = 8080
web-url        = "https://example.com"
webroot        = "/path/to/my-site/public"
org-source     = "/path/to/my-site/org"
snippet-output = "/path/to/my-site/html"
template       = "resources/templates/html5-page-layout"
footer         = "My Site © 2026"

[database]
dbname = "my-site.db"
#+END_SRC

*** Step 5 — Configure gimel.el

Create =.dir-locals.el= in your project root:

#+BEGIN_SRC emacs-lisp
((nil . ((gimel-config-file  . "/home/you/.config/gimel/my-site.toml")
         (gimel-auto-publish . t))))
#+END_SRC

~gimel.el~ reads the TOML file automatically when you open a file in the project. The port and directory paths are set from the config — you don't need to duplicate them here.

*** Step 6 — Start the ~gimel~ server

From the gimel repository root:

#+BEGIN_SRC sh
lein run -- -c /home/you/.config/gimel/my-site.toml
#+END_SRC

*** Step 7 — Write your first page

Create =my-site/org/index.org=:

#+BEGIN_EXAMPLE
#+TITLE: My First Page
#+AUTHOR: Your Name

* Hello, gimel

This is my first page.

\*\* A Section

Some content here.
#+END_EXAMPLE

Open the file in Emacs. When you save it, ~gimel.el~ will:

1. Convert the Org-mode file to an HTML snippet in =html/=
2. Ping the ~gimel~ server via =GET /api/export=
3. The server renders the full site into =public/=

You should see =gimel site exported= in the minibuffer. Your rendered page is now in =public/index.html=.

*** What's next?

- Add a navbar by creating =org/navbar.org= — gimel.el will post-process its links to absolute paths automatically
- Customise the template — see the [[file:guide.org::*Template System][Template System]] section of the full guide
- Trigger a full rebuild with =M-x gimel-batch-process-org-files= after making changes that affect all pages

For complete reference documentation, see [[file:docs/guide.org][guide.org]].
